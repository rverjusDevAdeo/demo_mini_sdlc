# Add Docstrings

Whenever you write or edit a function, give it a docstring:

- **One-line summary** first, in the imperative mood (e.g. `"""Return the remainder of a divided by b."""`).
- For non-trivial functions, follow with a short `Args:` / `Returns:` / `Raises:` block.
- Add a **module-level docstring** at the top of the file if one is missing.
- Keep docstrings accurate and concise — they must match what the code actually does.

Do not change behavior; only add or improve documentation strings.
